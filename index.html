FAQ
Common questions
Is it free? Do I need an account?
Yes, 100% free, no account or sign-up. Everything runs client-side in your browser.
Where does the data come from?
Direct public APIs from each exchange or provider — Binance, Hyperliquid, FRED, Etherscan, mempool.space, CryptoCompare, and alternative.me. No news scraping, no mocked numbers.
Why do some tabs ask for an API key?
Etherscan and FRED require a free personal key for their APIs. It's stored only in your browser's local storage and never sent anywhere else.
Some exchanges show no data — why?
A few exchanges don't allow direct browser requests (CORS). Installing a CORS browser extension resolves this for those specific exchanges.
Is this financial advice?
No. This is a research and data tool. Nothing here is a recommendation to buy, sell, or hold any asset.
Does it work on mobile?
Yes, in a modern mobile browser, though the dashboards are built with a desktop research workflow in mind.
